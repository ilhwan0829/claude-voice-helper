# 클로드 도우미 (Claude Voice Helper)

빅스비로 실행하면 Claude 앱의 '영어공부' 대화를 열고 버튼을 대신 눌러 주는 안드로이드 앱입니다.

| 빅스비에게 | 동작 |
|---|---|
| "딕테이션 열어줘" | 영어공부 대화 → 마이크(받아쓰기) 버튼 |
| "프리토킹 열어줘" | 영어공부 대화 → 음파(음성 대화) 버튼 |
| "지식백과 열어줘" | 지식 대화 → 음파(음성 대화) 버튼 |
| "공부 끝 열어줘" | 받아쓰기·음성 대화 모두 끄고 홈으로 |

## APK 받기
폰에서 https://github.com/ilhwan0829/claude-voice-helper/releases/latest 에 들어가 `claude-helper.apk` 를 눌러 내려받아 설치.

## 처음 설정
1. 설정 → 접근성 → 설치된 앱 → 클로드 도우미 켜기
2. '클로드 도우미 설정' 앱에서 테스트 버튼으로 확인
3. 버튼을 못 찾으면 '진단: Claude 화면 기록' → 기록 복사 후 Claude에게 전달
